# AVEN App

A React Native / Expo shopping app for AVEN, with native navigation and controls. This is not a WebView wrapper.

Website: https://github.com/TarunK951/AVEN

## Included

- Editorial Home screen, department/category browsing, price sorting, and size/color/price/sample-stock filters
- Product galleries, image viewer, size/quantity selection, local reviews, stock alerts, recently viewed pieces and browsing-based recommendations
- Search with local recent searches, persistent favorites and shopping bag
- Local account/profile editor, saved addresses with default selection, and checkout autofill
- My Orders, receipt details, sample tracking, local cancellation/return/exchange requests and buy-again
- Support FAQs and saved drafts, local activity/preferences, AVEN Circle preview rewards and delivery/currency estimates
- Address, standard/express shipping, demo payment, optional separate billing, and confirmation screens
- AVEN10 demo discount and totals calculated in integer cents
- Local photography, AVEN launcher icon/splash, and Android/iOS identifier `com.tarunk951.aven`

Bag, favorites, order history, profile, explicitly saved addresses, reviews, browsing history, preferences, requests and support drafts are stored locally with AsyncStorage. Profile/address saving is explicit; edits made only in checkout stay in screen memory. Receipts do not store street/contact details. No real card data is collected, and no payment, real order, shipment, support message, push notification or email is sent. Use fictional data for this prototype. Currency estimates use illustrative fixed rates; checkout remains USD.

## Run

Node 22 and npm are used by this project.

```sh
npm install
npm start
```

For an Android development build with Android Studio/SDK configured:

```sh
npm run android
```

On macOS with Xcode configured:

```sh
npm run ios
```

This app uses Expo SDK 58. Use a development build matching the project SDK; do not assume an arbitrary installed Expo Go version is compatible. Native Android/iOS folders are generated by Expo Prebuild and are not committed.

Browser preview:

```sh
npm run web
# Or use a predictable local port:
npm run start:local
# Then open http://localhost:8086
```

## Validation

```sh
npm run typecheck
npm test
npx expo-doctor
npm run export:web
npm run export:android
```

Tests cover cart variant merging, invalid data, catalog pricing, quantity limits, address validation, postal codes, shipping thresholds, discounts, and total reconciliation. See `QA.md` for verified run results and remaining platform limitations.

## Windows Android builds

The config plugin in `plugins/withBuildSettings.js` limits Gradle/Kotlin parallelism and shortens native CMake object paths. These project settings do not modify global Windows settings. Build one emulator architecture at a time when local RAM is limited. Generated native files and build artifacts are ignored by Git.

## Scope and assets

Prices, sizing recommendations, delivery rates, and tax are demo information. Live accounts, inventory, payments, fulfillment, push notifications, and store distribution are not integrated.
